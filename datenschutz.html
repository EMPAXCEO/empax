2. Bearbeitung beim Besuch der Website

Diese Website wird als statische Seite über GitHub Pages ausgeliefert. Diese Daten dienen dem sicheren Betrieb und werden nicht von uns zu Profilen zusammengeführt.

3. Cookies und Tracking

Diese Website setzt keine eigenen Cookies und verwendet keine Analyse- oder Trackingdienste.

4. Schriftarten

Für die Darstellung werden Schriftarten von Google Fonts geladen. Dabei wird Ihre IP-Adresse an Google übermittelt. Wenn Sie das vermeiden möchten, können die Schriftdateien lokal in das Projekt eingebunden werden.

Das Kontaktformular auf dieser Website überträgt keine Daten an einen Server, sondern öffnet Ihr E-Mail-Programm mit einer vorbereiteten Nachricht. Senden Sie uns eine E-Mail oder rufen Sie an, bearbeiten wir die von Ihnen mitgeteilten Angaben ausschliesslich zur Beantwortung Ihres Anliegens.

6. Aufbewahrung

Wir bewahren Personendaten nur so lange auf, wie es für den jeweiligen Zweck erforderlich ist oder gesetzliche Aufbewahrungsfristen es verlangen.
